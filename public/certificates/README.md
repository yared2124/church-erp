# የሰርቲፊኬት ፎርም ምስሎች (Certificate Form Images)

Please copy or save your scanned church certificate template images in this directory with the following exact filenames:

1. **የጥምቀት ምስክር ወረቀት (Baptism Certificate)**:
   - File path: `/public/certificates/baptism-template.png` (or `.jpg`)

2. **የተክሊል / የጋብቻ ምስክር ወረቀት (Holy Matrimony / Wedding Certificate)**:
   - File path: `/public/certificates/wedding-template.png` (or `.jpg`)

### Printing Modes:
- **Print onto Pre-printed Church Paper (የታተመ የቤተክርስቲያን ወረቀት ላይ ማተም)**:
  The background image is visible on-screen for alignment/preview, but automatically hidden during printing so ink is only printed onto the blank fields of your church's physical paper.
- **Full Print with Certificate Form (ሙሉ ፎርሙን ከነምስሉ ማተም)**:
  Prints both the form and the populated text fields onto blank paper.
